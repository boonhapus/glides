## Debug

- Built for bugs that **stump normal agents**: a loop around **runtime evidence** with **your verification**.
- Develops **Hypotheses** → **Adds** logging → **Reproduce** confirmation → **pinpoint** a surgical fix.

***You confirm the fix.** If not, **Debug** adds more  logging and asks you to **reproduce** again.*
