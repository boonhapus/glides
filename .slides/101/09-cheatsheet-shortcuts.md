## Cheatsheet | Keyboard

- **Toggle Sidepanel** — `Ctrl/Cmd` + `I`
- **Cycle Agent Modes** — `Shift` + `Tab` with the sidepanel open
- **New Chat** — `Ctrl/Cmd` + `N` with the sidepanel open
- **Cursor Settings** — `Ctrl/Cmd` + `Shift` + `J`
- **Command Palette** — `Ctrl/Cmd` + `Shift` + `P`
