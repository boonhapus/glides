# Commands — Scoped Context Injection

Commands are **user-triggered prompts** that tell the agent what task to perform and may load the relevant rules/skills for that task.

- Instead of the AI guessing what's relevant, commands **narrow the window** to what matters
- Good command design = lean context with high relevance
- Bad command design = loading everything "just in case"

> A command is how you say: *"For this task, here's exactly what you need to know."*
