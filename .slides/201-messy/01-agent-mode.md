# Agent Mode & The Problem It Creates

Agent Mode is a great pair programmer — it plans, writes, edits, and runs code with minimal hand-holding.

But the more autonomy you give it, the more you feel the friction:
- Why does it forget what you told it an hour ago?
- Why do you have to repeat yourself across sessions?
- How do you stop it from doing something you didn't want?

The answer to all three is the **context window**.
