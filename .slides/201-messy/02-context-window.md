# What Is the Context Window?

The context window is the AI's **short-term memory** — everything it can see and reason about *right now*.

- Measured in **tokens** (~¾ of a word each)
- Has a **hard limit** — once full, older content drops off or the request fails
- Resets between sessions — **the AI remembers nothing by default**

> Think of it like a whiteboard. The AI can only respond to what's written on the board.
> Once the board is full, you have to erase something to write something new.
